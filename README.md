# Sistema-de-Seguran-a-com-Senha-Din-mica
Aplicação web gamificada que simula um painel de controle de cofre com autenticação multifator (TOTP), trava de emergência (Lock-In), terminal dinâmico e integração de mídia.

# 🤠 HQ do Rancho - Sistema de Autenticação Interativo

Um painel de login dinâmico e gamificado desenvolvido em **JavaScript Vanilla**, **HTML5** e **CSS3**, simulando o cofre de segurança de um QG com funcionalidades avançadas de lógica de autenticação.

## 🚀 Funcionalidades Principais

- **Terminal Interativo:** Exibição dinâmica de status e logs do sistema no estilo linha de comando.
- **Sistema de Lock-In:** Bloqueio automático da interface após 3 tentativas incorretas com disparo de alarme sonoro.
- **Algoritmo TOTP Simulado:** Geração de chave dinâmica de segurança a cada 30 segundos enviada ao console dos Administradores.
- **Design Responsivo:** Interface personalizada estilo Cyberpunk/Country com suporte a áudio em tempo real.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Animações, temas escuros e layout responsivo)
- **JavaScript (ES6+)** (Lógica de autenticação, timers e manipuladores de eventos)
- **Web Audio API** (Efeitos sonoros do alarme)
